# Workflow làm việc thực tế

## Workflow khi nhận dự án
1. Nhận dự án
2. Clone từ main về local
3. Tạo 1 nhánh riêng để làm việc từ main
4. Làm việc từ local
5. Push code lên remote repo (nhánh riêng)
6. Review code change từ nhánh riêng so với nhánh gốc (main)
7. Create pull request (tạo yêu cầu merge code vào nhánh chính)
8. Người được assign review change
9. Comment và đưa lại cho người làm code (nếu cần)
10. Nếu review done -> merge code vào main
11. Tại local -> checkout main -> pull code mới của main về local
