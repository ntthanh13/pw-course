# Bonus: Playwright action key
| STT | Tên action   | Mô tả |
|-----|--------------|------|
| 1   | click        | Hàm click dùng để thực hiện click vào các phần tử trên trang web |
| 2   | fill         | Hàm fill dùng để điền văn bản vào các trường input hoặc textarea trên trang web |
| 3   | type         | Hàm type dùng để nhập từng ký tự một vào phần tử, mô phỏng hành vi gõ phím thực tế của người dùng |
| 4   | hover        | Hàm hover dùng để di chuyển con trỏ chuột đến vị trí của phần tử, kích hoạt các hiệu ứng hover |
| 5   | check        | Hàm check dùng để đánh dấu checkbox hoặc radio button, đảm bảo phần tử ở trạng thái checked |
| 6   | uncheck      | Hàm uncheck dùng để bỏ đánh dấu checkbox, đảm bảo phần tử ở trạng thái unchecked |
| 7   | selectOption | Hàm selectOption dùng để chọn một hoặc nhiều option trong thẻ select dropdown |
| 8   | press        | Hàm press dùng để mô phỏng việc nhấn phím bàn phím như Enter, Tab, Escape hoặc các phím khác |
| 9   | dblclick     | Hàm dblclick dùng để thực hiện double click (nhấp đúp chuột) vào phần tử trên trang web |
| 10  | dragAndDrop  | Hàm dragAndDrop dùng để kéo một phần tử từ vị trí nguồn và thả vào vị trí đích trên trang web |
